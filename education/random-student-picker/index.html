    With "No repeats" on, each name is drawn once per cycle and removed from the pool until everyone has been picked; the counter shows how many names are still unpicked. When the pool is empty the picker says everyone has been picked — reset starts a fresh cycle. With the box unchecked, every draw picks from the full list, so repeats are possible. Names are used exactly as you type them: blank lines are skipped, duplicates are kept, and leading/trailing spaces are trimmed. All draws happen in your browser; your list is never sent anywhere.

    Assumptions: Draws use your browser's random number generator; every name in the pool has an equal chance on each draw. Editing the list starts a fresh cycle, and duplicates are treated as separate entries.
